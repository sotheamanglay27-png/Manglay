CAMBODIA ROYALE 3D — ENHANCED VISUAL PROTOTYPE

អ្វីថ្មីក្នុងកំណែនេះ៖
- ពន្លឺ និងស្រមោល 3D កាន់តែស្អាត
- ផ្ទៃទឹកជុំវិញកោះ និងឆ្នេរខ្សាច់
- ភូមិខ្មែរ ផ្ទះ ដំបូលពណ៌ក្រហម ដើមឈើ និងផ្លូវដី
- តួអង្គមានសម្លៀកបំពាក់ កាបូប និងម៉ូដែលកាំភ្លើង
- ប៊ូតុង Touch សម្រាប់ទូរសព្ទ៖ ដើរ បង្វិលមើល លោត និងបាញ់
- បែបបទបើកលេង និង HUD ថ្មី

របៀបសាកល្បង៖
1. ដាក់ឯកសារ index.html, style.css និង game.js នៅក្នុង root នៃ GitHub repository ដដែល។
2. បើក Settings > Pages ហើយប្រើ Deploy from a branch / main / /(root)។
3. បើក Visit site តាម Chrome នៅលើ Android។ ត្រូវការអ៊ីនធឺណិតដើម្បីទាញយក Three.js ពី CDN។
4. ចុច PLAY រួចប្រើ joystick ខាងឆ្វេង និងប៊ូតុងខាងស្ដាំ។

សំខាន់៖ នេះនៅតែជាគំរូសាកល្បង (prototype) មិនមែន ROS Legacy ពេញលេញទេ។
- មិនទាន់មាន Multiplayer ពិតប្រាកដ ឬ server។
- ប៊ូតុង FIRE បង្ហាញតែ effect មិនទាន់មាន damage ឬ enemy AI។
- ម៉ូដែលតួអង្គ និងអគារត្រូវបានបង្កើតដោយរូបធរណីមាត្រ 3D សាមញ្ញ មិនមែន asset ពី ROS Legacy។
- GitHub Pages អាចបង្ហោះតែ static website; មិនដំណើរការ game server ទេ។
